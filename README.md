Recently completed my Power BI project based on the Global Superstore dataset. The project mainly focuses on analyzing sales data and converting raw data into interactive dashboards for better understanding of business performance.

The dashboard includes different sections like Executive Summary, Trend & Growth Analysis, Sales Breakdown, Market Analysis, and AI Insights. Added multiple visuals such as KPI cards, line charts, donut charts, maps, tables, decomposition tree, and word cloud to analyze sales, profit, quantity, shipping cost, category performance, and regional performance.

Also implemented interactive Power BI features like slicers, drill-through, bookmarks, filters, and Q&A visuals to make the dashboard more user-friendly and interactive.

Some key insights observed from the project: Technology category generated high profit Office Supplies had the highest sales contribution

Sales growth improved over the years
Standard Class shipping mode was mostly preferred
Canada and North Asia showed strong performance
This project helped me understand dashboard designing, data visualization, and how Power BI can be used to analyze business data more effectively.
